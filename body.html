Vision-language OCR pipeline for clinical documents

A PDF extraction system that converts 200+ page clinical study protocols into structured JSON. It keeps the section hierarchy, tables and figures intact across page breaks.

inputClinical PDF, 200+ pages
→

correctionLLM checks headings against the TOC

outputStructured JSON

reviewFastAPI + React UI
  • Built the extraction pipeline on dots.mocr, a 3B-parameter vision-language model with a Qwen2 decoder and a 42-layer vision transformer.
  • Designed an LLM correction layer that checks each heading against the document's own table of contents to fix systematic misclassification.
  • Rule-based heuristics had measurably failed on this problem. The TOC-grounded approach cut false headings by a third.
  • Exposed the pipeline through FastAPI services with a React front end for reviewers.

Research

Peer-reviewed work from my M.Tech, presented at an IEEE conference.

IEEE · ICICT 2025 8th International Conference on Inventive Computation Technologies Tribhuvan University, Nepal · 23–25 April 2025

Oral Disease Detection using Advanced Hybrid Deep Learning Model

DOI 10.1109/ICICT64420.2025.11005143

Oral diseases, including oral cancer, are usually diagnosed late, when treatment works less well. This paper presents a hybrid model that pairs DenseNet-169 for spatial feature extraction with an LSTM for contextual analysis, so it can pick up fine disease patterns on images of the tongue. It classifies six tongue conditions and outperforms state-of-the-art CNNs on accuracy, robustness and generalisation. The approach is non-invasive and scalable, aimed at early diagnosis in clinical oral health.
